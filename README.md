# KKuTu
A customizable Node.js server for the online word game KKuTu.
끄투(KKuTu) 게임을 위한 커스터마이징 가능한 Node.js 서버입니다.
[쪼리핑님의 끄투 레포지토리](https://github.com/JJoriping/KKuTu)를 기반으로 만들어졌습니다.
